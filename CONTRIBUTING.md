# Contribuir a Assets Creator

¡Gracias por tu interés en contribuir a Assets Creator! 🎉

## 🚀 Cómo Contribuir

### Reportar Bugs

Si encuentras un bug:

1. Verifica que no esté ya reportado en [Issues](https://github.com/tu-repo/assets-creator/issues)
2. Crea un nuevo issue con:
   - Descripción clara del problema
   - Pasos para reproducir
   - Comportamiento esperado vs actual
   - Versión de Node.js y sistema operativo
   - Logs relevantes

### Proponer Features

Para proponer nuevas funcionalidades:

1. Abre un issue con etiqueta "feature request"
2. Describe claramente el problema que resuelve
3. Proporciona ejemplos de uso
4. Discute alternativas consideradas

### Pull Requests

1. **Fork** el repositorio
2. **Crea una branch** desde `main`:
   ```bash
   git checkout -b feature/mi-feature
   ```
3. **Desarrolla** tu feature:
   - Sigue las convenciones de código existentes
   - Añade tests si es posible
   - Actualiza documentación
4. **Commit** con mensajes claros:
   ```bash
   git commit -m "feat: añade generación de videos"
   ```
5. **Push** a tu fork:
   ```bash
   git push origin feature/mi-feature
   ```
6. **Abre un Pull Request** con:
   - Descripción clara de cambios
   - Referencias a issues relacionados
   - Screenshots si aplica

## 📋 Convenciones

### Commits

Usamos [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` nueva funcionalidad
- `fix:` corrección de bug
- `docs:` cambios en documentación
- `style:` formato, no cambia código
- `refactor:` refactorización
- `test:` añade tests
- `chore:` tareas de mantenimiento

### Código

- TypeScript estricto
- ESLint + Prettier
- Nombres descriptivos
- Comentarios en código complejo
- JSDoc para funciones públicas

## 🧪 Testing

```bash
npm test
npm run build
```

## 📚 Documentación

Al añadir features:

- Actualiza README.md
- Añade ejemplos en `/examples`
- Documenta APIs públicas

## 🤝 Code Review

Todos los PRs requieren:

- ✅ Tests pasando
- ✅ Code review de maintainer
- ✅ Documentación actualizada
- ✅ Sin conflictos con main
